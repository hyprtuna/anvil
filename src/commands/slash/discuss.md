Invoke the brainstorming skill for structured decision capture.

1. Join all arguments into a topic string.
2. Load the `brainstorming` skill + resolved model.
3. Surface gray areas, ask clarifying questions, record locked decisions.
4. Produce a decisions summary.

## Equivalent CLI

`anvil discuss <topic>`
