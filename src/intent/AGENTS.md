# src/intent/ — AI Developer Notes

Layer 1 — intent detection, routing, and phase management.

## Role

The `intent/` module is the v2 routing kernel. It sits at layer 1 alongside `skills/` — pure data (`intents.ts`) and detection logic that skills and higher layers consume.

## Files

| File | Responsibility |
|---|---|
| `intents.ts` | Canonical 12-intent table (`INTENT_DEFINITIONS`, `INTENT_NAMES`). Pure data — no I/O. **Single source of truth** for routing metadata. |
| `router.ts` | `detectIntents`, `pickTopIntent`, `buildRoutingDecision`, `route`. Consumes `intents.ts` + `skills/chain.ts`. |
| `context-signals.ts` | Intent delta computation from project context. |
| `decision-coverage.ts` | Workflow-guard gate — decision coverage check. |
| `phase-matrix.ts` | SDD phase-based directive resolution. |
| `research-gate.ts` | Research-gate predicate for the `plan` command. |
| `semantic-fallback.ts` | Fallback routing when no intent matches. |

## Single Source of Truth — `intents.ts`

`intents.ts` is the canonical definition for every routing surface. It drives:

1. **`src/core/routing-rules-content.ts`** — generated by `scripts/generate-routing-rules.ts`. Contains `ROUTING_INTENT_TABLE`, `ANVIL_ROUTING_RULES_CONTENT`, and `ANVIL_OC_ROUTING_CONTENT`. **Do not edit by hand.**

2. **The doctor row "routing-rules sync"** — detects when the generated file has drifted from `intents.ts`.

3. **CI check** — `bun run scripts/generate-routing-rules.ts --check` fails if the committed file diverges.

### How to update routing metadata

1. Edit `src/intent/intents.ts` (add/change `phrase`, `defaultAgent`, `defaultSkills`, etc.)
2. Run `bun run generate:routing-rules` to regenerate `src/core/routing-rules-content.ts`
3. Commit both files together.

Running `anvil doctor` will show `routing-rules sync: fail` if step 2 was skipped.

## Import Rules

- `intents.ts` — may be imported by any layer (pure data, no deps outside `node:` built-ins).
- `router.ts` — imports from `skills/` (layer 1); can be imported by hooks (layer 2) and above.
- All other files — layer 1; no imports from layer 2+.

## Adding a New Intent

1. Add the `IntentName` union member.
2. Add the `IntentDefinition` entry to `INTENT_DEFINITIONS`.
3. Run `bun run generate:routing-rules`.
4. Verify `anvil doctor` passes.
5. Add a corresponding agent/skill if needed.
